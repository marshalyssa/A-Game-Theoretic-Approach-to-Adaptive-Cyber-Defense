## Overview

The Cybersecurity Decision Agent is a web-based platform for live IOC analysis, integrating external Cyber Threat Intelligence (CTI) feeds, Bayesian threat profiling, Game Theory modeling, and Reinforcement Learning (RL) agents. It allows analysts to input IOCs, map them to MITRE ATT&CK techniques, predict attacker profiles, and recommend optimal defensive actions.

## Data Flow

1. User inputs IOCs on the Frontend (`app.js`).
2. Frontend calls Backend (`server.cjs` -> `/api/cti/lookup`) to fetch CTI data from external APIs (OTX, VirusTotal, AbuseIPDB) or uses `cti-manager.js`.
3. Backend fetches and caches CTI data, returning it to Frontend.
4. Frontend (`live-monitor.js`) applies Bayesian inference to determine the attacker profile based on CTI mappings (MITRE ATT&CK).
5. Frontend (`game-engine.js`) computes optimal defensive actions.
6. The analysis, alongside selected actions, is sent back to the Backend (`/api/ioc/save`, `/api/ioc/rl-experience`) to be saved in SQLite (`db-manager.cjs`).
7. Stored experiences can be used to train RL agents (Q-Learning and DQN) via `/api/rl/q-table` and `/api/ioc/rl-replay`.
